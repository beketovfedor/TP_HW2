_Система для управления рецептами_

Система позволяет создавать рецепты блюд, добавляя необходимые для них ингридиенты (и их количество). Система позволяет масштабировать количество ингридиентов в зависимости от требуемого количества порций, а также составляет список продуктов для похода магазин, объединяя ингридиенты из разных рецептов в списке. 

Запуск:
   в терминале на своем компьютере последовательно введите следущие команды, чтобы запустить проект:
     git clone https://github.com/beketovfedor/TP_HW2.git
     cd TP_HW2
     pip install -r requirements.txt
     pytest
